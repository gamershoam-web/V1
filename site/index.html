Java Edition (PC / Mac / Linux)

  1. Open Minecraft: Java Edition and click Multiplayer.
  2. Click Add Server.
  3. Enter Orbitnetwork.net as the Server Address.
  4. Click Done, then double-click the server to join.

Bedrock Edition (Mobile / Console / Win)

  1. Open Minecraft and tap Play, then Servers.
  2. Scroll down and tap Add Server.
  3. Server Address: Orbitnetwork.net
  4. Port: 19132, then tap Save and join.
