    The plan

    From Microsoft's ISO to V1 in five stages

    You start from the official Windows 11 ISO, and every change happens on your own PC in scripts you can read. Like AtlasOS, the setup above also runs on a Windows install you already have, with no reinstall.

    • Official ISO

      You download Windows 11 from microsoft.com. No pre-modified image changes hands.

    • Builder

      build-iso.ps1 mounts install.wim with DISM, strips about 40 inbox apps, adds V1's files and repacks it.

    • Hands-off install

      autounattend.xml gives a local account and skips the ad and consent pages. No clicks during install.

    • V1 Setup

      The screens above. Opens at first sign-in in a WebView2 window. Every toggle runs one PowerShell file.

    • Playbook

      Registry, services, tasks, power plan, theme. Logged to C:\V1\log.txt, with one-click revert.
